CASE-05

Cloud vulnerability case pipeline

A pipeline that turns a Wiz issue into a tracked case automatically, with an enriched Jira ticket and a Slack channel for the owners.

Type
Project I designed and built
Role
Owner, from design to rollout
Outcome
Every qualifying Wiz issue becomes a tracked case automatically

Overview

An automated flow for cloud security findings: Wiz raises an issue, Torq enriches it and decides whether it needs a case, a Jira ticket is created, and a Slack channel opens with the owners.

Each case carries its context from the start and closes itself when Wiz confirms the fix, so analysts spend their time on remediation rather than tracking.

Why this matters

  • Finding issues is easy; closing them is the job. CSPM tools produce thousands of findings, and the value is in getting the right ones fixed.
  • Automation is a core SOC skill now. Senior analyst roles increasingly ask for SOAR and scripting, not just triage.
  • Context speeds up remediation. An owner who gets the resource, severity and exposure in one place can act without a back-and-forth.

How it works

  1. Wiz raises an issue

    For example, a critical vulnerability on an internet-exposed workload.

  2. Torq enriches and decides

    The workflow adds the resource, owner, severity and exposure, then decides whether the issue needs a case.

  3. Jira ticket is created

    Tickets are structured per cloud resource, with each Wiz issue tracked under it.

  4. Slack channel opens with the owners

    The channel is linked to the ticket, so the conversation and the record stay together.

  5. Case closes on confirmation

    Status flows back, and the case closes when Wiz confirms the issue is resolved.

Outcome

  • Case creation, ticketing and owner notification are fully automatic
  • Every case arrives enriched with resource, owner, severity and exposure
  • Owners and SecOps work each case in one dedicated channel, linked to its ticket
  • Cases close on Wiz confirmation, so status stays accurate without manual updates
